# Deprecated

Files in this folder are **no longer used by the running app** but are kept
for historical reference. Do not import from here.

## Layout

- `legacy-pages/` — old wiki pages replaced by the new dynamic wiki system.
- `docs/` — superseded status reports, session summaries, optimization
  checklists, and the original handwritten Discord/Supabase SQL drafts.
  Active documentation lives in `Documentations/` and the new
  `CHAT_BRIDGE_SETUP.md` at the project root.
- `scripts/` — one-off developer scripts (e.g. `check-staff.js`).

If you're sure something here is dead weight, it's safe to delete the whole
folder.
